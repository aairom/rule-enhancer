# Project structure
- Source code starts directly under the project root.
- Documents (except `README.md`) go in `Docs/` (see `documents.md`).
- Bash scripts go in `scripts/` and must be executable (`chmod +x`). Skill: `project-lifecycle-scripts`.
- Input documents in `input/`, results in `output/` (see `input-output-folders.md`).
- This project's `AGENTS.md` overrides the global one in `~/.bob`.
